# Показ прототипа RAG

Демонстрационный срез охватывает **21 статью dev**. В пакете семь связанных CSV, 5 447 извлечённых числовых записей и отчёт проверки. Для показа достаточно локального пакета. Интернет и API-ключ понадобятся только для нового извлечения.

## Открыть демо

На ноутбуке с репозиторием из его корня:

```powershell
python scripts/serve_ui.py out_jury_deepseek_v1/csv
```

Откройте [обозреватель на порту 8000](http://127.0.0.1:8000/). Для показа на другом компьютере распакуйте `jury-demo-deepseek-v1.zip` и запустите `python scripts/serve_ui.py csv` из папки пакета. Можно также открыть `app/index.html` в браузере и выбрать папку `csv` через «Открыть пакет CSV».

## Сценарий на три минуты

1. **Задача.** Превращаем измеренные результаты из научных PDF в сравнимые записи. Вход — PDF, выход — публикации, конфигурации, датасеты, задачи, эксперименты, результаты и замечания.
2. **Одна запись.** На вкладке «Результаты и сравнение» выберите D007 и фильтр «Проверенные». В карточке покажите исходное и нормализованное значения, номер страницы и дословную цитату. Затем на вкладке «Проверка и замечания» выберите D021 и найдите `Unverified OCR quotation`. Спорное наблюдение сохраняется с локатором и описанием проблемы.
3. **Как проверили.** На 21 статье и 19 392 эталонных записях Strict P/R/F1 составляет **0,27766 / 0,07596 / 0,11929** (1 473 TP), Loose — **0,50952 / 0,13939 / 0,21889** (2 703 TP). Strict дополнительно требует совпадения датасета, варианта метода, генератора и отсечения метрики. У всех 21 статьи есть Loose-совпадения. Проверка структуры семи CSV прошла. Часть цитат и условий ещё требует ручной проверки.
4. **Запуск без кэша.** DeepSeek получает текст с номерами страниц и структурой таблиц. Для сканов текст локально распознаёт RapidOCR. Промежуточные ответы валидируются и записываются в кэш v2, поэтому незавершённый документ можно продолжить. Результаты на 90 слепых статьях ещё предстоит измерить после приёмки.

## Живая проверка и точка возврата

Для новой выборочной проверки заполните `DEEPSEEK_API_KEY` по шаблону `.env.example`. Команда создаёт отдельные кэш и выгрузку.

```powershell
python main.py --input dev --only D016 --cache out_dev_live/cache --output out_dev_live/csv --workers 1 --ocr
```

Код прототипа закреплён тегом `jury-demo-deepseek-v1`. Чтобы открыть его независимо от текущей рабочей ветки:

```powershell
git fetch origin --tags
git worktree add --detach ../viniti-jury-demo jury-demo-deepseek-v1
```

Перенесите туда демонстрационный ZIP или запустите его из отдельной папки. Локальный архив `rollback-cache.zip` содержит замороженный dev-кэш для пересборки и хранится рядом с демонстрационным ZIP. Для пересборки нужен исходный набор PDF. В эталонной демо-выгрузке D021 дополнительно проверена с `--ocr`.
