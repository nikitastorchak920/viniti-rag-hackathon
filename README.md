# RAG Atlas · извлечение данных из научных PDF

**Жюри:** [комплект сдачи и быстрый запуск](SUBMISSION.md). В Atlas доступны две предметные области: тонкоплёночные солнечные элементы и RAG.

Пайплайн извлекает результаты из научных PDF через DeepSeek, хранит ответы в `cache/<id>.json` версии 2 и экспортирует семь связанных CSV. В локальном корпусе 111 статей: 21 в `dev/` и 90 в `test/`. Правила и метрики проверяются на `dev/`. Полный прогон извлечения на `test/` требует приёмки MVP и подтверждения оператора. Для показа используйте [сценарий демонстрации](DEMO.md).

## Работа на двух ноутбуках

- Codex меняет код, проводит ревью, запускает pytest и проверяет изменения пересборкой из кэша без API.
- Codex публикует задания в [очереди Antigravity](handoff/FOR_ANTIGRAVITY.md). Antigravity после `git pull --ff-only origin main` берёт самое новое задание без ответа, проводит проверку на своём ноутбуке и отправляет ответ с тем же ID через Git в [журнал отчётов](handoff/FROM_ANTIGRAVITY.md). Codex читает этот журнал при следующей проверке `origin/main`.
- Оператор принимает демонстрации и подтверждает переход к следующей фазе. Чтобы только посмотреть последнее сообщение из репозитория, выполните `git fetch origin main`, затем `git show origin/main:handoff/FROM_ANTIGRAVITY.md`.

## Установка

```powershell
git pull --ff-only origin main
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt -r tools/requirements.txt pytest
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

На Linux активируйте окружение через `source venv/bin/activate`. Для живого извлечения задайте `DEEPSEEK_API_KEY` в окружении или локальном `.env`. При необходимости укажите адрес шлюза, модель и лимит ответа по `.env.example`. Для пересборки из кэша и просмотра CSV ключ не нужен. Ключи, PDF, кэш и результаты остаются вне Git.

## Проверка и демонстрация

```powershell
python -m pytest tests/test_core.py tests/test_schemas.py
python main.py --input dev --cache out_dev_recovery/cache --output out_dev_rebuild --rebuild-csv-only
python tools/check_submission.py out_dev_rebuild dev --json-report out_dev_rebuild/validation.json
python scripts/evaluate.py out_dev_rebuild dev_gold --show-diffs 0
python scripts/serve_ui.py --rag out_jury_deepseek_v1/csv --solar out_solar_dev
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/) и переключайте области в шапке. Путь для каждой области — отдельный каталог с семью CSV. Нажатие на результат открывает карточку «Путь одного числа». Для отметки отдельной цитаты нужна запись о проверке с её ID, страницей и текстом. Если отчёт содержит только сводку, KPI цитат показывает её при совпадении количества строк в таблицах.

Сначала используйте пересборку из существующего `cache/`: она не обращается к API. При необходимости повторите обработку только проблемных документов. Например, для одной статьи:

```powershell
python main.py --input dev --cache out_dev_retry/cache --output out_dev_retry/csv --only D021 --ocr --workers 1
```

`--force` используйте для выбранных ID только при замене завершённого кэша. DeepSeek получает текст с номерами PDF-страниц и HTML-разметкой таблиц. Для сканов используйте `--ocr`: RapidOCR распознаёт текст локально. Если после OCR текста недостаточно, документ получает статус `SKIPPED_SCAN` в журнале и остаётся не обработанным в выгрузке. После выборочного запуска пересоберите полный пакет.

`main.py` возвращает 1 при неполной обработке. Когда есть успешно обработанные документы, частичный пакет содержит явные заглушки для остальных. `check_submission.py` возвращает 0 при чистой проверке, 1 при структурных ошибках, 2 при открытых замечаниях. Описание таблиц, нормализации и статистика — в [DATASET_PASSPORT.md](DATASET_PASSPORT.md).

## Дополнительные режимы

- `--rebuild-csv-only --include-partial-cache` добавляет в диагностический экспорт уже сохранённые окна незавершённых документов. Частичные статьи помечаются в `issues.csv`, а команда возвращает ненулевой код.
- Восстановление однозначно распознанных ячеек PDF-таблиц включено по умолчанию. Для контрольного сравнения используйте `--no-recover-table-cells`. Извлечение приблизительных значений из векторных графиков включается отдельно флагом `--recover-plot-points`.
- В текстовом режиме каждая распознанная таблица обрабатывается со своей подписью, секцией и заголовками. Длинные таблицы делятся по строкам, а оставшийся текст обрабатывается постраничными окнами. DeepSeek возвращает компактные массивы, которые при записи разворачиваются в обычные записи кэша v2.
- Возобновление незавершённого кэша с постраничным текстом использует сохранённые метаданные и старый размер окна. DeepSeek передаёт новый паспорт сущностей компактными массивами и разворачивает их перед записью JSON.
- Первый запрос формирует паспорт сущностей статьи. Для каждой таблицы учитываются её датасеты, конфигурации и явно указанные пороги метрик. Экспорт извлекает `metric_k` из записи `Metric@k` и сохраняет исходное название с `@k` в CSV.
- На официальном DeepSeek API по умолчанию используется `deepseek-flash` с лимитом ответа 393 216 токенов. Для собственного API-шлюза задайте поддерживаемые модель и лимит через `DEEPSEEK_MODEL` и `DEEPSEEK_MAX_TOKENS`.
- `--local --skip-scans`: локальные эвристики без API.
- `--ocr-json DIR`: импорт локальных OCR-JSON.
- `scripts/merge_cache.py`: объединение локально переданных кэшей и пересборка экспорта.
