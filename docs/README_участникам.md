# Кейс ВИНИТИ — предметная область 2: RAG

**Статус комплекта: подготовка.** PDF и рекомендуемый шаблон подготовлены. Полный эталон завершён для 21 из 21 dev-статьи; список и границы покрытия — в `dev_gold/README_STATUS.md`. Комплект ещё не готов к итоговой оценке.

| Путь | Содержание |
|---|---|
| dev/ | 21 статья, D001–D021; 3 PDF представлены синтетическими сканами |
| dev_gold/ | Открытый эталон всех 21 dev-статей; границы покрытия указаны внутри |
| test/ | 90 статей, P001–P090; 14 PDF представлены синтетическими сканами |
| submission_template/ | Семь пустых CSV, описание полей и машиночитаемая схема |
| tools/check_submission.py | Проверка структуры, значений, связей и цитат |
| CHECKLIST.txt | Перечень 111 PDF, страницы, размеры и SHA-256 |

Предметная область — только Retrieval-Augmented Generation. Системы извлекают сведения из внешней коллекции и используют найденный контекст при формировании ответа. Предметные условия и критерии кейса не меняются. Структура каталогов заимствована из примера ВИНИТИ, таблицы адаптированы под сущности RAG. Формат рекомендуется для машинного сравнения результатов и не вводится как новое требование условий.

Источник каждой статьи — оригинальный PDF. В версии scan-stress-v1 около 15% документов каждого раздела намеренно заменены синтетическими сканами: 3/21 dev (14,29%) и 14/90 test (15,56%). Округление выполнено до ближайшего целого файла. Остальные 94 PDF сохранены без изменений.

Синтетические варианты получены растеризацией всех страниц с перекосом, шумом, размытием, сжатием, неравномерным освещением и небольшой волной строк. В них нет скрытого текстового слоя. Это искусственное испытание устойчивости извлечения, а не реальные архивные сканы. Количество, порядок, размеры страниц и видимые научные сведения сохранены. Оригиналы хранятся у организаторов; эталонные значения и номера страниц относятся к тем же источникам.

Для разработки доступны сканы D002, D013 и D021 и их разметка в dev_gold. D/P — условные имена файлов: названия, авторы и DOI остаются видимыми на страницах. Это нумерация файлов, а не анонимизация содержания.

В исходном примере было 21 dev-статья с пропущенным D011. В нашем наборе используется непрерывный ряд D001–D021. Нумерация не выражает сложность или качество статьи.

Корпус содержит сложную вёрстку, таблицы, формулы и графики. Наличие графики не означает отсутствие текстового слоя. Автоматические оценки сложности служат для отбора PDF и не являются эталоном извлечения.

Сначала прочитайте `submission_template/README.md`. В `publications.csv` нужна строка для каждого PDF проверяемого набора, включая исключённые по содержанию. Неизвестные сведения не восстанавливаются по догадке. Номер источника — номер страницы в файле PDF, начиная с 1.

```bash
python -m pip install -r tools/requirements.txt
python tools/check_submission.py ПАПКА_С_CSV test --json-report report.json
```

Код 1 означает ошибку, код 2 — необходимость проверки источников или предупреждений. Успешная техническая проверка не подтверждает полноту и научную правильность извлечения. Открытый эталон `dev_gold` охватывает все 21 dev-статьи; ограничения разметки указаны в его README_STATUS.md. Скрипт проверен 31 тестом, включая OCR, сохранение знаков и чисел и поведение при недоступном OCR.

Для страниц без текстового слоя включите дополнительную проверку OCR:

    python tools/check_submission.py ПАПКА_С_CSV test --ocr --ocr-language eng --json-report report.json

Для этого нужен отдельно установленный Tesseract с языковыми данными; путь к исполняемому файлу можно указать через --tesseract. Сам OCR не меняет PDF и не публикует его содержимое. Он выполняется локально только для страниц без извлекаемого текста. Если Tesseract недоступен или цитата не распознана буквально, результат остаётся непроверенным (код 2), а не автоматически ошибочным или правильным. Ненайденную цитату проверяют по изображению страницы. Скрипт не исправляет знаки, числа и опечатки OCR.

Эталон test, соответствие номеров test исходным статьям и резерв корпуса в пакет участников не входят.
