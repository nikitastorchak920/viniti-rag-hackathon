# Комплект для жюри ВИНИТИ + ЮФУ

Запускайте команды из корня репозитория. Ранее зафиксированный демо-комплект доступен в версии `atlas-jury-v1`.

## Показ на ноутбуке жюри

```powershell
python scripts/serve_ui.py
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для просмотра достаточно Python 3.10+ и браузера. Сеть и API-ключ для показа не нужны. Переключатель в шапке открывает «01 Тонкоплёночные солнечные элементы» и «02 RAG и поиск по документам».

| Область | Папка в архиве | Зафиксированный dev-замер |
|---|---|---|
| 01 Solar | [results/solar-dev](../results/solar-dev/) | 21 статья, 741 строка результатов. Strict+Label F1 0,324, Schema-Strict F1 0,750, Medium F1 0,812, Loose F1 0,915. Отчёт подтверждает 895 из 895 проверенных цитат. |
| 02 RAG | [results/rag-dev](../results/rag-dev/) | 21 статья, 5 447 строк результатов. Strict F1 0,11929 (1 473 TP), Loose F1 0,21889 (2 703 TP). Отчёт подтверждает 7 255 из 8 168 проверенных цитат. |

В каждой папке лежат семь заполненных CSV и `validation.json`. Для Solar отчёт содержит итог по пакету. Для RAG отчёт также содержит проверки отдельных цитат. [Шаблоны и схема RAG](../submission_template/). [Сценарий показа](DEMO.md).

Замер RAG воспроизводится командой `python scripts/evaluate.py results/rag-dev dev_gold --show-diffs 0`. История экспериментов описана в [аудите метрик](METRIC_AUDIT.md).

## Выгрузка RAG на test

[Семь CSV и отчёт проверки](../results/rag-test-partial/) соответствуют архиву, подготовленному для отправки жюри. Из 90 статей 44 обработаны полностью, 6 частично, 40 отмечены как необработанные. В таблице результатов 13 340 строк. Проверка нашла 0 структурных ошибок, по текстовому слою подтверждены 17 233 из 19 656 цитат. Метрики Strict и Loose на закрытой выборке отсутствуют, поскольку её эталон недоступен.

## Извлечение на входных PDF жюри

Установите зависимости из `requirements.txt` и `tools/requirements.txt`. Укажите свой `DEEPSEEK_API_KEY` по `.env.example`. Подставьте каталоги соответствующих PDF в команды. Режим `--ocr` включает локальное распознавание страниц с недостаточным текстовым слоем.

```powershell
python scripts/run_solar.py --input "./pdf_solar" --cache cache_solar --output out_solar_run --ocr
python main.py --input "./pdf_rag" --cache cache_rag --output out_rag_run --ocr
```

Для повторного извлечения используются PDF, предоставленные организаторами. Ключи и сырые кэши хранятся локально.
