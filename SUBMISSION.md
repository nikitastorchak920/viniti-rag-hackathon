# Комплект для жюри ВИНИТИ + ЮФУ

Версия кода закреплена тегом `atlas-jury-v1`. Архив `atlas-jury-v1.zip` содержит код, две зафиксированные dev-выгрузки и их отчёты. Запускайте команды из корня распакованного архива.

## Показ на ноутбуке жюри

```powershell
python scripts/serve_ui.py
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для просмотра достаточно Python 3.10+ и браузера. Сеть и API-ключ для показа не нужны. Переключатель в шапке открывает «01 Тонкоплёночные солнечные элементы» и «02 RAG и поиск по документам».

| Область | Папка в архиве | Зафиксированный dev-замер |
|---|---|---|
| 01 Solar | `out_solar_dev/` | 21 статья, 741 строка результатов. Strict+Label F1 0,324, Schema-Strict F1 0,750, Medium F1 0,812, Loose F1 0,915. Отчёт подтверждает 895 из 895 проверенных цитат. |
| 02 RAG | `out_jury_deepseek_v1/csv/` | 21 статья, 5 447 строк результатов. Strict F1 0,11929 (1 473 TP), Loose F1 0,21889 (2 703 TP). Отчёт подтверждает 7 255 из 8 168 проверенных цитат. |

В каждой папке лежат семь заполненных CSV и `validation.json`. Для Solar отчёт содержит итог по пакету. Для RAG отчёт также содержит проверки отдельных цитат. `submission_template/` содержит шаблоны и схему RAG. Порядок полей CSV для Solar определён в `plugins/solar/exporter.py`. Файл `SHA256SUMS.txt` в архиве фиксирует контрольные суммы содержимого. Сценарий показа — в [DEMO.md](DEMO.md).

Замер RAG воспроизводится на открытом dev-эталоне из архива: `python scripts/evaluate.py out_jury_deepseek_v1/csv dev_gold --show-diffs 0`. Для Solar в архиве сохранён отчёт исходного контрольного прогона.

## Извлечение на входных PDF жюри

Установите зависимости из `requirements.txt` и `tools/requirements.txt`. Укажите свой `DEEPSEEK_API_KEY` по `.env.example`. Подставьте каталоги соответствующих PDF в команды. Режим `--ocr` включает локальное распознавание страниц с недостаточным текстовым слоем.

```powershell
python scripts/run_solar.py --input "./pdf_solar" --cache cache_solar --output out_solar_run --ocr
python main.py --input "./pdf_rag" --cache cache_rag --output out_rag_run --ocr
```

Выше приведены результаты на dev. Замеров на слепых наборах в архиве нет. Исходные PDF предоставляются отдельно. Архив для жюри включает готовые CSV, код и отчёты без ключей и сырых кэшей.
